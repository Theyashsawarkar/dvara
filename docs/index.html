Dvara (द्वार) is Sanskrit for "gateway": the doorway every app is opened through.

dvara is the app launcher for Vyom: one keyboard-driven panel that opens instantly, with live data, a preview and a key for everything. It runs on any compositor with the layer-shell protocol (sway, Hyprland, river, niri, Wayfire, labwc…). In Vayu, the desktop it was built for, it replaces wofi's app launcher (wofi --show drun).

#Features

  • Every installed app (.desktop files), with its real icon.
  • Ranked by how often and how recently you open each app. With an empty search, a dock of your 8 most-used apps as big icons sits above the list (1..8 opens one, left to right; a green dot marks a running one), then what's running, then everything A–Z.
  • Matches the name, the generic name ("Web browser"), keywords and the command, typos and all; the letters that matched are highlighted in peach, so you can see why "frf" found Firefox.
  • Running apps say so ("Running · 2 windows", in green) and Enter switches to them instead of opening another (on sway and i3); Ctrl+Enter opens a new window.
  • The preview shows the app's open windows with their workspace (click one to switch to it), how often you've opened it, and its own actions (New window, Private window…) as buttons, each on Alt+1..9.
  • Shift+Enter runs whatever you typed as a command in a terminal; a row below the results runs it without one.
  • Keyboard first: every action has a key, shown in the footer; the mouse works too.
  • Never freezes the panel: slow commands run in the background.

#Install

#Requirements

  • Vyom 0.6.0 or newer (Python 3.11+, PyGObject, GTK 4, gtk4-layer-shell, a Nerd Font)
  • optional: swaymsg (open-window counts)

#Install

git clone https://github.com/Theyashsawarkar/dvara ~/.local/share/vyom/plugins/dvara
vyom reload           # pick it up (or log out and in)
vyom dvara            # open it; run it again to close

Give it a key in your compositor, e.g. sway:

bindsym $mod+<key> exec vyom dvara

#Update and uninstall

git -C ~/.local/share/vyom/plugins/dvara pull && vyom reload     # update
rm -rf ~/.local/share/vyom/plugins/dvara && vyom reload          # uninstall

#Usage

Open it with vyom dvara (or your key). It opens in insert mode: type to search, Enter opens. Esc goes to normal mode, where every key is a command and Space is the leader (a strip lists what comes next); i types again. The footer always shows the keys for what's selected.

Vyom's keys work too (every vim tool has them): ? and Space ? list every key, Space Space is the palette, j / k move, gg / G jump, / searches again, H / L switch tabs, q closes, Space u f is fullscreen, Esc steps back.

Insert mode (typing; dvara opens in it)

#Troubleshooting

  • Nothing opens. vyom list shows every installed tool, and why one is skipped (a missing requirement, or a Vyom that's too old).
  • It opened, then something failed. Look for a Traceback in the daemon's log, journalctl --user -u vyom -u vyom-daemon -b (without systemd: ~/.local/state/vyom/daemon.log), and open an issue with it.
  • No blur or rounded corners. That's the compositor: on SwayFX, add layer_effects "vyom" { blur enable; corner_radius 20; shadows enable }.
